About the project

From image to prediction

This demo uses a PyTorch ResNet18 classifier trained on PathMNIST, a benchmark dataset of colon pathology image patches. The browser handles the upload and presentation, while FastAPI preprocesses the image and runs inference on the server.

For educational and demonstration purposes only. This model is not intended for clinical diagnosis.
